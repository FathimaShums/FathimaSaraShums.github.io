# Fathima Sara Shums — Portfolio

Clean, corporate portfolio for GitHub Pages.

## Publish on GitHub Pages

1. Create a new **public** GitHub repository named exactly:
   `FathimaShums.github.io`
2. Upload `index.html`, `style.css`, and `CV.pdf`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Your site will appear at:
   `https://FathimaShums.github.io`

## Before publishing

- Put your latest CV in this folder and name it `CV.pdf`.
- Confirm your LinkedIn URL in `index.html`.
- Review the project links and wording.
